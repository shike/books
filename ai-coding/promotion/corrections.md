## 勘误格式

每条勘误按以下格式记录:

```
### [YYYY-MM-DD] 章节号 - 错误类型
**原内容**:"..."
**修正为**:"..."
**报告人**:[姓名 / 匿名]
**影响**:轻微 / 中等 / 严重
```

## 配套资源快速入口

- **代码仓库**:`https://github.com/shike/books`(顶层 books 仓库的 `ai-coding/` 子目录)
  - 全书 10 个案例的源码、配置、踩坑笔记;每次厂商版本更新后,会同步标注差异。
- **配套提示词库**:`https://github.com/shike/books/tree/main/ai-coding/assets/prompts`
  - 16 个"完整提示词"段(含前言的工程助理基线版本)与各章的子提示词,提供 Markdown 源文件与一键复制版本。
- **公众号**:施可(见 [`wechat_qr.png`](wechat_qr.png))
- **读者群**:扫描封底"施可个人微信二维码"加好友,备注"读者群",24 小时内拉入

## 使用建议

- 读完全书后,先在配套仓库的 README 中核对最新修订;再回到正文,把所有"具体型号"替换为当下使用版本,方法论部分无需替换。
- 在提示词库中复制"工程助理"基线版本,先在自己常用的 AI 工具里跑一次,确认 AI 已"进入角色",再叠加各章任务。
