## 4. 实践步骤

1. 接入企业 IM 工具,Agent 在群里常驻,WebSocket 长连接 + 心跳保持会话存活
2. 路由规则:@ 触发 / 关键词触发 / 定时触发,误触发的前 2 小时专人盯
3. 70/30 拆分:70% 任务用隔离子 Agent(不污染主会话),30% 留在主会话(需要上下文的)
4. 最小权限:Agent 只能访问汇总层、不能修改业务数据、只能 @ 授权人员
5. 异常暂停:未知情况 Agent 暂停任务并通知相关人员,异常日志完整可查

## 5. 常见坑

- 把 AI 当工具用(临时启动) — 临时启动是工具,常驻才是虚拟员工;岗位级自动化的前提是会话常驻
- Agent 能 @ 全员 — 出异常时影响半径过大,应分频道分授权,异常时不污染全员频道
- 心跳间隔和飞书服务端超时阈值不一致 — 长连接在不一致时静默断,服务不可用但无人察觉
