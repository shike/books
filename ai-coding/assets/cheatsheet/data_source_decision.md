# 数据源决策速查表

> 配套《AI Coding:人人都是程序员》第 14 章。可打印贴在墙上。
> "公开可见" ≠ "开放取用" — 抓取前先查商业 API 授权,授权费通常远低于一次律师函 + 数据全删的代价。

## 1. 三类数据源分工

| 数据源 | 适用场景 | 成本结构 | 时效性 |
|---|---|---|---|
| **内置知识** | 常识(天气、地理、历史、通用知识) | 零边际成本 | 滞后 6—12 个月 |
| **联网搜索** | 时事(股价、新闻、最新版本) | 按调用付费,不可控 | 实时 |
| **爬虫 + 知识库** | 自有数据(公司文档、行业资料、用户行为) | 一次性建库,边际成本趋零 | 自控 |

**核心判断**:"答案用完即弃"用搜索,"数据反复使用"用爬虫建库。两者成本结构完全不同。

## 2. 数据源决策四问

```
问题 1:时效性是否关键?(数据是否需当日/小时级)
├── 是 → 排除"内置知识",进入下一问
└── 否 → 可用内置知识

问题 2:数据是否公开时事(新闻/股价/版本号)?
├── 是 → 优先联网搜索,进入下一问
└── 否 → 进入下一问

问题 3:是否需要批量(每天 ≥ 50 条)?
├── 是 → 爬虫自建 + 知识库(边际成本趋零)
└── 否 → 联网搜索即可

问题 4:是否需要可复现、可审计(报告/合规)?
├── 是 → 爬虫自建(可控 + 可追溯)
└── 否 → 联网搜索(便宜省事)
```

四个"是"指向爬虫自建,其他组合对应搜索或内置知识。

## 3. 爬虫五类工具横评

| 类型 | 代表 | 月成本 | 适用场景 | 隐性成本 |
|---|---|---|---|---|
| 浏览器自动化 | Playwright / Selenium | $0 + 工时 | 反爬严格、需 JS 渲染 | 1 周反爬工程 |
| 开源爬虫框架 | Scrapy / Crawl4AI | $0 + 工时 | 通用、大规模 | 部署与维护 |
| 托管 API | Firecrawl / Tavily | $7—8/1k 次 | 快速上线、稳定 SLA | 长期订阅累计 |
| 搜索引擎 API | Brave / Exa / Tavily | 按调用 | 时事、新闻、研究 | 速率限制 |
| 综合搜索生成 | Perplexity Sonar | $1/$1 token 起 | 一体化检索+生成 | 不能单独计费 |

**选择经验**:
- 团队能承担 1 周反爬工程 → 选 Crawl4AI 等开源
- 团队不愿投入工程 → 选 Firecrawl 等托管 API
- "免费"不是零成本,只是成本从订阅费变成工时

## 4. 五条运营红线

- [ ] **查 robots.txt**:违反 = 律师函合规事故
- [ ] **控制抓取频率**:每秒 ≤ 1—2 次,设随机间隔
- [ ] **不缓存用户个人信息**:缓存 = 个人信息保护法红线
- [ ] **优先商业 API 授权**:商业 API 授权费 < 律师函 + 数据全删
- [ ] **设合规检查清单**:每次抓取动作前过一遍 5 条红线

## 5. MCP 接入速查

- MCP(Model Context Protocol)是 Agent 接入数据工具的标准化协议
- 接入新数据源:从"写定制对接逻辑" → "修改一行配置"
- 选型:评估数据源是否提供 MCP 服务(否则回到爬虫五类)
- 安全:同 14.5 红线 + Agent 最小权限
