# Books · 施可的三本书

> 三本书从不同视角回答同一个问题:**AI 时代怎么做事**。
>
> 作者:[施可 (Shi Ke)](https://shike.github.io/) — shike@dropleap.cn

| # | 书 | 一句话介绍 | 适合谁 |
|---|---|---|---|
| ① | [AI Coding:人人都是程序员](./ai-coding/) | 让非技术人用 AI 做出真实、可收款、可维护的产品 | 创业者 / 产品经理 / 设计师 / 独立顾问 |
| ② | [FDE：AI的胜负不在模型](./fde/) | AI 项目的胜负不在选哪个模型,而在部署交付 | CTO / 技术负责人 / 产品经理 / 工程师 |
| ③ | [WorkBuddy 三部曲](./workbuddy/) | 管理者用桌面 AI:从个人,到团队,到组织 | 中层及以上管理者 / 带团队用 AI 的人 |
