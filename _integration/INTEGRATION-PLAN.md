## A. 写作口味对齐

### A1. 三本书现状(调研数据)

| 项 | ai-coding | fde | workbuddy |
|---|---|---|---|
| 章节标题格式 | `## 1.1 选型的真实单位:工作方式而非模型` | `## 一个故事` `## 为什么这个故事是 FDE 的定义` | `## 1.1 你的真实工作负荷,比你以为的更重` |
| 章节号格式 | `1.1` / `1.1.1` 三级 | **无章节号**,用小标题 | `1.1` / `1.1.1` 三级 |
| 章首导读 | ✅ "本章导读"段 | ❌ 无(直接进故事) | ✅ "本章学习目标" |
| ch01 开头 | 行业现象描述 + 框架建立 | 故事开场(2019 秋,陈柏宇) | 算术题 + 表格 + 痛点共鸣 |
| ch01 人称 | 你 17 / 我 2 / 他 15(以"你"为主) | 你 27 / 我 19 / 他 36(**故事+对话**) | 你 59 / 我 18 / 他 22(以"你"为主) |
| 引用风格 | 学术 `[^1^][^7^]` | 无 | 无 |
| 表格密度 | 中(决策树 + 对比表) | 少(故事优先) | 高(步骤表 + 路由表 + 路由权重) |

| 章节末"小结" | ❌ 无 | ❌ 无 | ✅ "本章小结" |
| 章节末"行动建议" | ❌ 无 | ❌ 无 | ✅ "明天你可以..." |

### A2. 差异分类

**结构差异**(可统一):
- 章节号格式(fde 无编号 → 建议加)
- 章首导读(ai-coding/workbuddy 有,fde 无 → 建议补)
- 章节末小结/行动(fde 无 → 建议补)
- 引用风格(ai-coding 学术,fde/workbuddy 无 → 保留差异,因为主题不同)

**风格差异**(保留,这是定位差异):
- ai-coding:行业分析 + 战略框架(读者是创业者 / 团队 leader)
- fde:故事化叙事 + 行业案例(读者是 FDE 工程师 / 实施团队)
- workbuddy:实用指南 + 即学即用(读者是管理者)

**这是"系列感"的关键**——三本书面向不同读者,**统一会失去定位**。但要在"系列级 front matter"上做对齐。

### A3. 建议方案

| 方案 | 动作 | 工作量 | 优先级 |
|---|---|---|---|
| **A3-1:三本书保留各自风格(定位差异)** | 不动正文风格,只在"系列 front matter"对齐(共同的开场页 + 共同的读者指南 + 共同致谢格式) | 1-2 小时 | 🟡 推荐 |
| **A3-2:章节号格式统一** | fde 26 章加 `1.1 / 1.2 / 2.1` 编号;ai-coding/workbuddy 不变 | 4-6 小时 | 🟢 可选 |
| **A3-3:fde 补章首导读 + 章末小结** | fde 26 章每章加 1 段导读 + 1 段小结/行动 | 8-10 小时 | 🟢 可选 |
| **A3-4:不调整(只动 front matter)** | 跳过 A3-2/A3-3,只做 A3-1 | 1-2 小时 | 🟢 备选 |

**我推荐 A3-1(只对齐系列 front matter,正文风格不动)**。理由:三本书的读者群不同,正文风格差异是定位需要,不是 bug。统一会破坏"为不同读者写"的设计。
