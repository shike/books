# 第 6 章 提示词:从"问问题"到"派活"

> **本章学习目标**
> 1. 理解 WorkBuddy 提示词的核心原则:不是"问",是"派活"。
> 2. 掌握"五段式提示词":角色 + 任务 + 约束 + 素材 + 输出。
> 3. 学会 10 个高频场景的提示词模板,可直接复制使用。
> 4. 知道常见坑,避开"AI 输出不行"的 80% 原因。

> **界面示意图,具体界面以你安装的 WorkBuddy 版本为准。**

## 6.1 核心思维转变:从"问"到"派"

多数人用 AI 的方式是"问"——"帮我写封邮件""总结下这个 PDF""分析下这个数据"。

**这种"问"的方式,AI 输出质量上限是 60 分**——因为它不知道:
- 你要这封邮件做什么(催进度?道歉?确认?)
- 写给谁(老板?客户?同事?)
- 你的偏好(直接还是委婉?长还是短?)
- 你有什么素材(具体数字、背景)
- 输出格式(邮件正文?PPT 大纲?表格?)

**WorkBuddy 的提示词哲学是"派活"**——不是"问 AI 一个问题",而是"**给 AI 布置一个具体任务**",任务里包含它完成工作所需的全部信息。

派活的 5 个要素:

```
你(角色)   →  你是谁、什么身份
做(任务)   →  具体做什么
按什么标准(约束)  →  长度、语气、风格
用什么素材(素材)  →  哪些文件、哪些数据
产出什么(输出)  →  最终格式
```

**这就是"五段式提示词"**——下一节详细讲。

## 6.2 五段式提示词详解

### 6.2.1 角色(可选,但推荐)

**写什么**:
```
你是一位资深的销售总监,有 10 年 B2B 销售经验,擅长用数据说话,语气务实但不刻板。
```

**为什么有用**:
- 激活 AI 在"这个角色"上的"训练偏好"(它会调用对应的"风格库")
- 防止 AI 用"通用语气"回复(对你来说没用)

**什么时候可以省**:
- 任务简单("把这段话翻译成英文")
- 你想要"中立"输出("列 5 个产品命名方向")

### 6.2.2 任务(必须)

**写什么**:
- 用"动词开头"——"整理"、"分析"、"写"、"改"、"对比"
- 具体说"做什么"——不要"帮我看看"这种模糊

**好 vs 坏**:

| 模糊(差) | 具体(好) |
|---|---|
| 帮我看看这个 PDF | 用 200 字总结这个 PDF 的核心结论和关键数据 |
| 写一封邮件 | 写一封催客户付款的邮件,语气委婉但坚定,250 字 |
| 整理一下会议 | 把这份会议转写整理成"决策 / 行动项 / 待定"三部分,1500 字 |

### 6.2.3 约束(必须)

**写什么**:
- **长度**:字数、页数、条目数
- **语气**:正式 / 委婉 / 直接 / 友好
- **结构**:必须包含哪些部分、按什么顺序
- **禁止项**:不能说哪些话、不能引用什么
- **风格**:商务体 / 文学体 / 学术体 / 口语

**示例**:
```
要求:
- 字数 200 字以内
- 语气对上级,既实事求是又体现你的思考
- 不要过度承诺或推卸责任
- 不要用"我们将""我们相信"这种空话开头
- 结尾要明确"下一步动作"
```

### 6.2.4 素材(可选,但强烈推荐)

**写什么**:
- 哪些文件(`~/Documents/...`)
- 哪些数据
- 哪些背景信息(关键事实)

**示例**:
```
素材:
- ~/Documents/Q3销售数据.xlsx(全表,2.3 MB)
- ~/Documents/邮件存档/9月/ 下的 .eml 文件
- 重点客户:阿里(年度合作 800 万)、字节(年度 500 万)、腾讯(年度 300 万)
- 已知问题:9 月阿里续约谈判比预期晚 2 周
```

**WorkBuddy 的优势**:它**自动读你授权的目录**,所以即使你不写素材,只要文件在工作目录里,AI 也能读到。但**写明"重点看哪些"**会让 AI 更精准。

### 6.2.5 输出(必须)

**写什么**:
- 输出格式(Markdown / HTML / 表格 / 列表)
- 输出文件(直接保存为 .docx / .pptx / .xlsx)
- 输出位置(具体路径)

**示例**:
```
输出要求:
- Markdown 格式,三级标题以下用列表
- 表格部分用 Markdown 表格语法
- 不要 emoji
- 完成后直接调用本地工具,保存为 ~/Documents/Q3复盘-初稿.md
```

## 6.3 五段式完整模板

把这 5 段拼起来,就是一条高质量提示词:

```
[角色]
你是一位资深的销售总监,有 10 年 B2B 销售经验,擅长用数据说话。

[任务]
基于我工作目录的 Q3 销售数据,生成 5 个值得讨论的洞察。

[约束]
- 每个洞察 100-150 字
- 不要空话套话,要"非显而易见"
- 必须有具体数据支撑
- 不要引用 Excel 里没有的字段
- 字数 800 字以内

[素材]
- ~/Documents/Q3销售数据.xlsx
- 字段:客户名 / 销售额 / 行业 / 区域 / 客户成功经理
- 已知背景:Q3 整体增长 27%,但 TOP 3 客户贡献 60%
- 上一季度问题:某行业整体下滑 15%

[输出]
- 5 个洞察,每条配 1-2 句"建议下一步"
- 用 Markdown 列表
- 完成后调用工具生成 5 张图,保存到 ~/Documents/Q3洞察/目录
```

**写一条这样的提示词,大概 5 分钟。但用一次能省 30-60 分钟**。

## 6.4 5 个场景的提示词模板(可直接复制)

### 6.4.1 周报生成提示词

```
[角色]
你是一位资深的中层管理者,擅长用简洁语言汇报工作。

[任务]
读取 ~/Documents/工作周报/{YYYY-Wnn}/ 目录下所有文件,
整理出本周(YYYY-MM-DD ~ YYYY-MM-DD)我的工作内容。

[约束]
- 字数 1500 字左右
- 结构:本周完成(分 3-5 条) / 进行中(分 2-3 条) / 问题与改进(分 2-3 条) / 下周计划(分 3-5 条)
- 每条 1-2 句话,具体到项目和数字
- 不要空话套话
- 数据必须从原始文件中提取,没有的标"待补充"

[素材]
- 该目录下所有 .eml / .txt / .docx / .md 文件

[输出]
- Markdown 格式,4 级标题
- 完成后调用工具保存为 ~/Documents/工作周报/{YYYY-Wnn}-初稿.md
```

### 6.4.2 邮件润色提示词

```
[角色]
你是一位资深的中国职场人士,擅长写专业邮件。

[任务]
把下面这段草稿改写成专业邮件。

[草稿]
[粘贴你的草稿]

[约束]
- 字数 200-300 字
- 语气:{委婉 / 直接 / 商务体 / ...}
- 结构:背景(2 句) / 问题(2 句) / 建议(2-3 句) / 下一步(1 句)
- 不要承诺不该承诺的事
- 不要用"我们将"、"我们相信"等空话

[输出]
- 邮件正文(包含主题)
```

### 6.4.3 PPT 大纲提示词

```
[角色]
你是一位资深的咨询顾问,擅长把复杂内容结构化。

[任务]
基于 ~/Documents/{汇报素材}/ 下的所有文件,生成 {N} 页 PPT 大纲。

[约束]
- 共 {N} 页
- 主体部分分 {3} 部分:{部分 1}({4} 页) / {部分 2}({4} 页) / {部分 3}({3} 页)
- 每页一个核心观点(一句话)
- 标注每页需要的图表类型
- 不要空话套话

[素材]
- 该目录下所有 .docx / .xlsx / .md

[输出]
- Markdown 格式
- 每页用 3 级标题
- 完成后调用本地 PowerPoint,生成 ~/Documents/{汇报}-初稿.pptx
```

### 6.4.4 会议纪要提示词

```
[角色]
你是一位资深的会议记录员,擅长捕捉关键信息和行动项。

[任务]
读取 ~/Documents/会议录音/{YYYY-MM-DD-会议名}/ 下的转写文件,生成会议纪要。

[约束]
- 包含:基本信息 / 议题 / 决策事项 / 行动项(表格) / 待定事项 / 下次会议
- 行动项必须有负责人和截止时间
- 决策和行动项要"明确",不要"再讨论"这种空话
- 字数 1500 字内

[素材]
- 该目录下所有 .txt / .srt / .vtt / .md

[输出]
- Markdown 格式
- 完成后保存为 ~/Documents/会议纪要/{YYYY-MM-DD-会议名}.md

### 6.4.5 数据透视提示词

```
[角色]
你是一位资深的数据分析师,擅长从数据中看出"非显而易见的洞察"。

[任务]

[约束]

- 每个洞察 100-150 字
- 必须有具体数据

[素材]

- 已知背景:{背景}

[输出]

- 5 个洞察 + 每条配"建议下一步"

## 6.5 高级技巧

### 6.5.1 "Few-shot"提示词(给 AI 看样例)

如果 AI 的输出"格式不对",最好的办法是**给一个样例**让它模仿:

```
[任务]
帮我写 3 个产品命名方向。

[样例]
产品名:智链
副标:让数据自己说话
一句话介绍:基于 AI 的销售数据分析平台,5 分钟出洞察,3 分钟做决策。

按这个格式,给我 3 个方向:
```

### 6.5.2 "分步"提示词(让 AI 一步步想)

如果 AI 输出"跳跃"或"漏思考",可以要求它**一步步**输出:

```
请一步步思考:
1. 第一步:这个 PDF 的核心论点是什么?
2. 第二步:作者用了哪些论据?
3. 第三步:论据之间有什么逻辑关系?
4. 第四步:作者可能在回避什么?

最后,基于这 4 步,给我 500 字总结。
```

### 6.5.3 "反例"提示词(告诉 AI 不要什么)

如果 AI 总是犯同一个错,用"反例"告诉它:

```
不要:
- 不要用"我们将"、"我们相信"开头
- 不要给"加强沟通"这种空泛建议
- 不要假设我没说过的事

[然后正常写你的任务]
```

### 6.5.4 "角色扮演"提示词(让 AI 站在对方角度)

写给老板/客户的邮件,你可能不知道"老板想看到什么"。让 AI 反过来:

```
假设你是我的老板(总监,务实但有耐心),看到我下面这封邮件草稿:
[草稿]

你会觉得:
1. 这封邮件是想"请示"还是"汇报"?
2. 我的建议合理吗?如果是你,你会怎么决策?
3. 我有没有"甩锅"或"推卸"的嫌疑?
4. 这封邮件的语气,对一个 32 岁的中层,合适吗?
```

## 6.6 常见坑

### 坑 1:提示词太短

"帮我写邮件" → AI 给你通用邮件,没用。

**解决**:5 段式至少 100-300 字。

### 坑 2:任务模糊

"看看这个 Excel" → AI 不知道要看什么。

**解决**:说"看 Q3 销售数据,出 5 个洞察"——明确**看什么 + 出什么**。

### 坑 3:约束缺失

没有字数、语气、结构要求 → AI 给你"万能版本",你 80% 不满意。

**解决**:明确字数、语气、结构。

### 坑 4:不迭代

第一次输出不满意,就重写整条提示词——浪费时间。

**解决**:**对话式迭代**——AI 给的差,你**直接说"哪里差"**:
- "第 3 部分太官方,改成大白话"
- "字数太多,砍到 200 字"
- "结尾缺行动项,加上"

### 坑 5:不保存模板

每次都重写 → 浪费时间。

**解决**:把"5 段式 + 任务描述"保存到收藏(第 5 章讲过),下次改日期/数据即可。

## 6.7 提示词库:WorkBuddy 的"团队共享"

WorkBuddy 提供"提示词库"功能(在左栏"技能市场"):

- **个人收藏**:你保存的提示词,只有你看到
- **团队共享**:团队成员共享的提示词,大家都能用
- **公共模板**:WorkBuddy 官方维护的高质量模板(每周更新)

**怎么用**:
1. 中栏输入框点"📝 模板"按钮
2. 选择"个人收藏 / 团队共享 / 公共模板"
3. 选一个模板,自动填入输入框
4. 修改日期/数据,提交

第二卷第 4 章会讲"团队共享提示词"的治理。

## 6.8 小结

本章我们讲了提示词的核心:

1. **从"问"到"派"**:不是问 AI 一个问题,是给 AI 布置具体任务
2. **五段式提示词**:角色 + 任务 + 约束 + 素材 + 输出
3. **5 个场景模板**:周报、邮件、PPT、纪要、数据
4. **4 个高级技巧**:Few-shot / 分步 / 反例 / 角色扮演
5. **5 个常见坑**:太短 / 模糊 / 缺约束 / 不迭代 / 不保存

**记住 3 个原则**:
- **写提示词 5 分钟,跑任务省 1 小时**
- **第一次输出不满意,直接说"哪里差",让 AI 改**——不要重写整条
- **好提示词 = 模板化**:把跑通过的提示词保存,下次改日期即可

## 6.9 实践练习

**练习 1:用五段式重写"周报提示词"**
- 拿你上周的真实周报(或者你脑子里想的)
- 用五段式重写提示词(角色 / 任务 / 约束 / 素材 / 输出)
- 在 WorkBuddy 跑一次
- 对比"之前的版本"和"五段式版本",看 AI 输出质量差异

**练习 2:用"反例"改造一个差提示词**
- 找一条你之前用过、AI 输出差的提示词
- 加"反例"——告诉 AI 不要什么
- 再跑一次,看是否改善

**练习 3:把 5 个模板保存到收藏**
- 把 6.4 节的 5 个提示词模板复制到 WorkBuddy 收藏
- 下周实际工作时,改日期/数据,直接调用
- 记录"用模板后,你修改的字数占比"——如果修改 > 30%,模板还要优化
