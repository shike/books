# 第 3 章 主界面与三栏布局

> **本章学习目标**
> 1. 掌握 WorkBuddy 主界面的三栏布局逻辑,5 分钟内形成肌肉记忆。
> 2. 理解每个栏目的设计意图,知道什么时候看哪里、点什么。
> 3. 学会 10 个最常用的快捷键,操作效率提升 50%。
> 4. 知道怎么自定义主界面,让它适配你的工作习惯。

> **本章所有界面截图均为教学示意图,非真实产品截图。**

---

## 3.1 三栏布局:一个总览

WorkBuddy 主界面采用**三栏布局**。这不是我们独创——很多现代桌面应用(GMail、Notion、Slack、VS Code、Microsoft Outlook)都采用三栏或类似的"导航-主体-详情"布局。它被证明是**管理文档型工作最高效的界面结构**。

打开 WorkBuddy 登录成功后,你会看到这样一个窗口:

```
┌─────────────────────────────────────────────────────────┐
│ [≡] WorkBuddy       任务:本周销售复盘      [模型: 自动 ▼] │  ← 顶部条
├──────────┬─────────────────────────┬─────────────────────┤
│          │                         │                     │
│  左栏    │        中栏             │       右栏          │
│ 导航     │      对话区             │     工具面板        │
│ 历史任务 │  (你跟 AI 的对话)       │  (文件/模型/日志)   │
│ 收藏     │                         │                     │
│          │                         │                     │
│          │                         │                     │
├──────────┴─────────────────────────┴─────────────────────┤
│ Credits: 47.2万/50万   [💬 输入提示词............] [提交] │  ← 底部条
└─────────────────────────────────────────────────────────┘
```

**三个栏目的角色**:
- **左栏**:导航。你能"去哪"——历史任务、收藏、文件夹、技能市场
- **中栏**:主体。你"做什么"——跟 AI 打字、收 AI 回复、看输出
- **右栏**:上下文。AI "用到什么"——文件、模型路由状态、当前任务关联的资料

**为什么是三栏,不是两栏或四栏**?

- 两栏(导航+主体)缺点:工具/上下文信息没地方放,要么挤在主体里(乱),要么藏到二级菜单(找不到)
- 四栏缺点:屏幕宽度有限,四栏每栏都太窄,眼动距离太长
- 三栏是**屏幕宽度 vs 信息密度**的最佳折中。左栏 200px、中栏 600px、右栏 300px(可调),在 1280×800 起步的笔记本屏幕上刚好

**重要原则**:WorkBuddy 是**以中栏为绝对中心**的设计。左右两栏都可以折叠/隐藏,**中栏永远在**。

## 3.2 左栏:导航、历史、收藏、技能市场

左栏宽约 200px(可调),从上到下分四个区:

### 3.2.1 顶部:新建任务 + 搜索框

```
┌────────────┐
│ + 新建任务  │  ← 蓝色主按钮
├────────────┤
│ 🔍 搜索...   │  ← 搜索历史/收藏
└────────────┘
```

**"+ 新建任务"** 点击后,中栏清空,聚焦输入框,你开始一条新任务。**注意**:WorkBuddy 不"切换页面",而是"在同一个对话区里开新对话"——这是和 Slack/微信类似的流式设计。

**搜索框** 可以搜:
- 历史任务的标题和内容
- 收藏夹里的提示词模板
- 技能市场里的 Skill(后面讲)

按 `Ctrl+K`(Windows)或 `Cmd+K`(macOS)可以**全局唤出搜索框**——你在任何地方都能跳到历史任务,不用先点左栏。

### 3.2.2 导航区:"去哪"

```
📁 我的任务
  📋 历史任务 (132)
  ⭐ 收藏 (8)
  📂 文件夹
    └ 我的工作目录
    └ 邮件存档
    └ 录音转写
  🛒 技能市场 (28)
  ⚙️ 设置
```

**我的任务** 是核心导航:
- **历史任务**:所有过去的任务列表,按时间倒序
- **收藏**:你标记为"重要"的任务
- **文件夹**:你授权给 WorkBuddy 的目录列表(可点开看文件)
- **技能市场**:团队共享的提示词模板库(第 6 章细讲)

**"⚙️ 设置"** 是关键入口:
- 文件夹授权
- 模型路由偏好
- 登录账号管理
- Credits 充值
- 主题/外观
- 高级选项(自动备份、API Key 等)

### 3.2.3 中部:历史任务列表

```
今天
  ✅ Q3 销售复盘  (3 小时前)
  ✅ 周报 - 9月第2周  (今早 09:23)
  🔄 数据透视 - 9月销售明细  (进行中)

昨天
  ✅ 邮件润色 - 客户A跟进  (昨天 18:40)
  ✅ 翻译 - 英文合同第3章  (昨天 14:10)

本周早些
  ✅ 整理会议纪要 - 跨部门会  (周一)
  ...
```

**每个任务显示 4 个信息**:
- 状态图标:✅(完成)/ 🔄(进行中)/ ❌(失败)
- 任务标题:AI 起的,或你起的
- 任务类型(图标):📋周报/📧邮件/📑PPT/🎙会议纪要/📊数据/...
- 时间:相对时间("3 小时前""今早""昨天")

**关键操作**:
- **单击**:在右栏打开任务详情(用了哪些文件、用了哪个模型、花了多少 Credits、最终输出)
- **双击**:在中栏重新打开这个任务,继续对话
- **右键**:更多操作(重新生成、删除、收藏、复制为新任务)

**重要设计**:**历史任务不只是"列表",而是"可重用的工作流"**。你上周帮客户A 写过一封跟进邮件,本周客户B 跟进时,你可以"复制为新任务",把上周的输入作为模板,改几个变量就成新的。这比"从头打字"快得多。

### 3.2.4 底部:状态信息

```
👤 施可  |  Pro 版  |  47.2万/50万 Credits
```

显示当前登录账号、订阅版本、Credits 余额。点这个区可以跳到"账户管理"页(充值、升级、改密码)。

## 3.3 中栏:你跟 AI 的对话区

中栏是 WorkBuddy 的**绝对中心**,宽度自适应,通常 500-800px。

### 3.3.1 顶部:任务元信息

```
┌──────────────────────────────────────────┐
│ 任务: Q3 销售复盘                        │
│ 模型: deepseek-v3(自动) | Credits: 1240  │
│ 文件: 邮件存档/9月/*.eml, 销售表.xlsx    │
├──────────────────────────────────────────┤
```

这一行显示当前任务的元信息:
- **任务标题**:AI 起的(基于你输入的提示词),可点编辑
- **模型**:这次实际用了哪个模型(自动路由的结果)。可手动点开下拉切换
- **Credits**:这次任务消耗的 Credits 实时显示
- **文件**:这次任务读了哪些文件(可展开看)

**"模型"那一行最有价值**——它告诉你**AI 这次是不是路由对了**。如果你发现"我让它写邮件,AI 却用了 Kimi(读长文档的模型)",说明路由有偏差,可以手动改。

### 3.3.2 中部:对话流

对话区是流式布局,新消息加在底部,从上到下读。每个消息有清晰的"谁说的"标识:

```
👤 施可  (3 小时前)  📋 周报任务
┌──────────────────────────────────────────┐
│ 请读取 ~/邮件存档/9月/ 下所有邮件,     │
│ 整理出本周(9月 8-14 日)我的工作内容,  │
│ 输出 1500 字周报。                       │
└──────────────────────────────────────────┘

🤖 WorkBuddy  (3 小时前)  ✏️ 已完成
┌──────────────────────────────────────────┐
│ 本周工作内容(9月 8-14 日):              │
│                                          │
│ 一、产品发布                              │
│ ...                                       │
│                                          │
│ 文件清单:                                │
│ - 邮件 23 封(已读)                       │
│ - 销售表 Q3.xlsx(已读)                   │
│                                          │
│ [复制] [导出为 .md] [导出为 .docx]      │
└──────────────────────────────────────────┘

👤 施可  (3 小时前)  📋 续问
┌──────────────────────────────────────────┐
│ 第三部分"问题与改进"再具体点,加数据    │
└──────────────────────────────────────────┘

🤖 WorkBuddy  (3 小时前)  ✏️ 已完成
┌──────────────────────────────────────────┐
│ 三、问题与改进                            │
│ ...                                       │
└──────────────────────────────────────────┘
```

**关键设计**:
- **每条消息可独立操作**:复制、重新生成(换一个模型)、编辑(改完后 AI 会基于你的修改继续)、引用(把这条消息作为上下文给下一个问题)
- **多轮对话不丢上下文**:你问"第三部分再具体点",AI 知道你说的"第三部分"是上一轮输出里的第三部分
- **超长输出自动分页**:如果 AI 输出超过 2000 字,会自动折叠,显示"展开全部"按钮。点开才看到全文

**图标含义**:
- 👤 你的消息
- 🤖 AI 的消息
- ✏️ 已完成 / ❌ 失败 / 🔄 进行中
- 📋 / 📧 / 📑 任务类型(基于提示词自动识别)

### 3.3.3 底部:输入区

```
┌──────────────────────────────────────────┐
│                                          │
│ 💬 输入提示词...                          │
│                                          │
├──────────────────────────────────────────┤
│ 📎 附加文件  🎙 语音  📝 模板  ⌨️ 快捷键  │  ← 工具栏
├──────────────────────────────────────────┤
│           Credits 余额 47.2万     [提交]  │
└──────────────────────────────────────────┘
```

**输入框** 是**多行富文本输入框**,支持:
- Markdown 语法(标题、列表、代码块、表格)
- 变量占位符 `{{文件名}}`(把当前已读文件当作变量,提示词里直接引用)
- 拖拽文件:把 PDF/Word/Excel 拖到输入框,自动作为附加文件

**工具栏四个按钮**:
- **📎 附加文件**:从你的授权目录里选文件作为输入(比拖拽更精细)
- **🎙 语音**:用语音输入(普通话、英语、粤语都可识别,识别后转文字)
- **📝 模板**:从你收藏的提示词模板里选一个(第 6 章细讲)
- **⌨️ 快捷键**:查看所有快捷键(下文)

**"提交"按钮** 也可以用 `Ctrl+Enter`(Windows)或 `Cmd+Enter`(macOS)替代。

### 3.3.4 中栏的"工具调用"可视化

当 WorkBuddy 帮你"读 PDF""写 PPT""发邮件"时,这些操作不是黑箱——**AI 会在中栏告诉你它在做什么**:

```
🤖 WorkBuddy  正在做这件事...  (实时状态)
┌──────────────────────────────────────────┐
│ ✓ 读取文件: Q3销售表.xlsx  (3 秒)         │
│ ✓ 提取关键字段: 销售额 / 客户数 / 退款率 │
│ ✓ 调用工具: 数据透视                      │
│ ⏳ 调用工具: Excel 图表生成...  (进行中)  │
└──────────────────────────────────────────┘
```

这种**"AI 在做什么"的可视化**,让你**始终知道 AI 现在的动作**,避免"AI 卡住了还是慢?"的焦虑。如果某步耗时超过 30 秒,会自动显示"复杂任务,稍等片刻"的提示。

## 3.4 右栏:工具面板、文件、模型路由

右栏宽约 300px(可调),默认显示"工具"标签页。右栏有 4 个标签:

### 3.4.1 "工具"标签页

```
┌──────────────────────────────────┐
│ 当前任务可用工具                 │
├──────────────────────────────────┤
│ 📂 读文件  PDF/Word/Excel/PPT/MD  │
│ ✏️ 写文件  生成 .docx / .pptx   │
│ 📧 邮件   起草 / 发送 / 归档     │
│ 📊 数据   Excel 透视 / 图表     │
│ 🎙 录音   转写 / 摘要 / 行动项   │
│ 🌐 搜索   联网搜索(可选)        │
│ 📅 日历   读取 Outlook / 飞书    │
│ 💬 IM    企业微信 / 飞书 / 钉钉  │
└──────────────────────────────────┘
```

每个工具都有详细说明(点击展开)。AI 在中栏跑任务时,会自动调用这些工具——你可以随时在右栏看到"AI 现在正在用什么工具"。

**核心工具一览**:

| 工具 | 作用 | 典型使用场景 |
|---|---|---|
| 读文件 | 读 PDF/Word/Excel/PPT/MD/CSV | 周报、会议纪要、数据分析 |
| 写文件 | 生成 .docx / .pptx / .xlsx | 汇报材料、报告 |
| 邮件 | 起草 / 发送 / 归档 | 跟进客户、催进度 |
| 数据 | Excel 透视 / 图表生成 | 销售分析、HR 分析 |
| 录音 | 转写 / 摘要 / 行动项 | 会议纪要、面试纪要 |
| 搜索 | 联网搜索 | 行业调研、查资料 |
| 日历 | 读 Outlook / 飞书日历 | 看会议安排 |
| IM | 企业微信 / 飞书 / 钉钉 | 跨部门消息、催办 |

**这 8 个工具的组合,覆盖了 80% 的管理者日常任务。**

### 3.4.2 "文件"标签页

显示当前任务"读/写"过的所有文件,以及文件状态(已读/正在读/未找到):

```
本任务文件
  ✓ Q3销售表.xlsx  (2.3 MB, 已读 3 张)
  ✓ 邮件 - 客户A.eml  (已读全文)
  ✗ 录音-9月会议.mp3  (未找到,可能未转写)
  ⏳ Q4 计划.docx  (正在读)
```

这个标签让你**审计 AI 用了哪些文件**——AI 不会"凭空生成"数据,它读过的文件都在这里列出。

### 3.4.3 "模型路由"标签页

显示当前任务的"模型路由决策"——为什么 AI 选了 X 模型而不是 Y 模型:

```
本次路由决策
  任务: 写一封催进度的中文正式邮件
  评分:
    DeepSeek     ★★★★☆  质量 8, 速度 9, 成本 9
    Kimi         ★★★☆☆  质量 7, 速度 7, 成本 8
    智谱清言     ★★★★★  质量 9, 速度 8, 成本 7  ← 选中
  决策原因: 智谱清言在"中文正式写作"任务上评分最高

[切换模型] [路由偏好设置]
```

**这个标签让你理解"AI 为什么这么做"**——不是黑箱决策。如果你不同意这个路由,可以点"切换模型"手动覆盖,或者调整"路由偏好"。

### 3.4.4 "日志"标签页

显示当前任务的所有操作日志,180 天保留:

```
[10:23:15] 任务开始, 用户: 施可
[10:23:18] 模型路由: 智谱清言, 原因: 中文写作强
[10:23:22] 读文件: Q3销售表.xlsx (2.3 MB)
[10:23:24] 提取字段: 销售额, 客户数, 退款率
[10:23:31] 调用工具: 数据透视
[10:23:33] 生成图表: 销售趋势.png
[10:23:40] 写文件: 销售分析报告.docx (1.2 MB)
[10:23:42] 任务完成, 总耗时 27 秒, 消耗 1240 Credits
```

**审计日志是 WorkBuddy 的核心差异化**。如果 AI 给你生成了错误的报告,你可以回溯"它基于哪些文件、用了哪个模型、得出了什么结论"。

## 3.7 10 个最常用的快捷键

熟练使用快捷键,操作效率提升 50%。WorkBuddy 默认快捷键(Windows 用 `Ctrl`,macOS 用 `Cmd`):

| 快捷键 | 作用 | 场景 |
|---|---|---|
| **Ctrl+K** | 全局搜索 | 跳到历史任务、收藏、文件 |
| **Ctrl+N** | 新建任务 | 开始一条新任务 |
| **Ctrl+Enter** | 提交输入 | 发送提示词 |
| **Ctrl+Shift+Enter** | 换行(不提交) | 输入多行提示词 |
| **Ctrl+/** | 切换左栏显示/隐藏 | 让中栏更宽 |
| **Ctrl+\\** | 切换右栏显示/隐藏 | 让中栏更宽 |
| **Ctrl+L** | 跳到输入框 | 直接开始输入 |
| **Ctrl+H** | 跳到历史任务 | 复用过去的提示词 |
| **Ctrl+,** | 打开设置 | 改配置 |
| **Ctrl+Shift+R** | 重新生成(用新模型) | 对当前回复不满意 |

**自定义快捷键**:"设置 → 快捷键" 里可以改。比如 `Ctrl+Shift+L` 我想换成"切换深色/浅色主题"。

## 3.8 主题与外观

WorkBuddy 默认是**浅色主题**,支持:

- **浅色**(默认):白底黑字,适合办公室
- **深色**:深灰底白字,适合长时间工作或夜间
- **跟随系统**:跟随操作系统的深色/浅色模式

**字体大小** 三档可调:小(适合信息密集)、中(默认)、大(适合演示或老花眼)。

**等宽字体**(代码块、表格):可指定用 Consolas / Menlo / 等系统字体。

## 3.9 折叠左右栏,获得"专注模式"

如果你的工作需要"长时间写一份长文档"或"读一份长报告",WorkBuddy 的三栏会显得拥挤。

**折叠左栏**:点左上角 `[≡]` 按钮,或按 `Ctrl+/`。左栏隐藏,中栏占据原来 80% 宽度。

**折叠右栏**:按 `Ctrl+\\`。右栏隐藏,中栏再增加 25% 宽度。

**两个都折叠**:中栏几乎占满整个屏幕,适合"沉浸式写文档"。

**随时调回**:**再按一次快捷键**就恢复。

## 3.10 自定义主界面

"设置 → 界面"里可以改:

- **左栏宽度**:150-400px(默认 200)
- **右栏宽度**:200-500px(默认 300)
- **中栏字号**:小/中/大
- **默认显示的标签页**:登录后右栏默认显示哪个标签(工具/文件/模型路由/日志)
- **历史任务默认排序**:时间倒序 / 字母序 / 任务类型
- **主题**:浅色 / 深色 / 跟随系统

**建议**:
- 如果你屏幕大(2K/4K),可以**加宽左栏到 250px、右栏到 350px**,信息更舒展
- 如果你屏幕小(13 寸笔记本),**缩窄到 150/250px**,中栏能更宽
- 第一次用先用默认,等用熟再调

## 3.11 移动版与多设备同步

WorkBuddy 主要是**桌面应用**,但支持**手机版**(微信小程序 + iOS/Android App),核心功能:
- 看历史任务(只读)
- 提交简单的提示词(比如"告诉我最近 3 天的销售数据")
- 接收任务完成的通知

**多设备同步**:你的工作目录、收藏、设置,都通过 WorkBuddy 账号云同步。换一台电脑登录,所有配置都在。

**注意**:文件本身**不上云**,只在本机。你换电脑后,需要重新授权新电脑的本地目录。

## 3.12 小结

本章我们讲了 WorkBuddy 主界面的三栏布局:

1. **三栏布局**:左(导航)/ 中(对话)/ 右(工具),中栏是绝对中心
2. **左栏**:新建任务、搜索、历史任务、收藏、文件夹、技能市场、设置
3. **中栏**:任务元信息 + 对话流 + 输入区 + 工具调用可视化
4. **右栏**:4 个标签(工具/文件/模型路由/日志),核心是"AI 用了什么、做了什么、为什么这么做"
5. **顶部条 + 底部条**:全局操作 + Credits 状态
6. **快捷键**:10 个最常用的,熟练后效率提升 50%
7. **专注模式**:折叠左右栏,获得更多中栏空间

**记住这 3 个原则**:
- 中栏是"做什么",是工作区
- 左栏是"去哪",是导航
- 右栏是"怎么做的",是审计

**下次打开 WorkBuddy,你的第一反应应该是**:左栏点历史任务(找上周的周报模板)→ 中栏改几个字 → 右栏看用了哪些文件 → 提交。
