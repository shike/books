## 2.2 Windows 安装流程(5 分钟)

下载 `WorkBuddySetup.exe` 后,双击运行。

### 步骤 1:启动安装

双击后,Windows 会弹出一个蓝色的安装窗口,显示"WorkBuddy 正在准备安装"——这是正常现象,首次启动需要 10-20 秒解压和验证。

### 步骤 2:同意许可协议

接下来,你会看到"许可证协议"页面,显示 WorkBuddy 的使用条款(用法律语言写了"你可以做什么、不可以做什么")。勾选"**我同意此协议**",然后点"**下一步**"。

### 步骤 3:选择安装位置

默认安装到 `C:\Program Files\WorkBuddy\`(系统盘),大约占用 500 MB 空间。如果你的 C 盘空间紧张,可以选择其他位置(比如 D 盘)。建议保持默认,**不要装到 OneDrive 同步目录**(会引发文件冲突)。

### 步骤 4:等待安装完成

点"**安装**"后,进度条会走 1-2 分钟。期间会创建桌面快捷方式、注册开机启动项(可关)、配置本地服务。

### 步骤 5:启动 WorkBuddy

安装完成后,自动勾选"**启动 WorkBuddy**",点"**完成**"。

第一次启动 WorkBuddy 时,**Windows Defender 或 360 等安全软件可能弹窗**,问你"是否允许 WorkBuddy 对设备进行更改?"——这是因为 WorkBuddy 需要**管理员权限**来读取你授权的文件夹、调用本地工具。

**点"是"**(或"允许")。如果弹窗来自 360 或腾讯管家,选择"信任"或"更多 → 始终信任"。

### 步骤 6:首次配置——文件夹授权

WorkBuddy 启动后,第一个弹窗是**文件夹授权**。这是 WorkBuddy 跟云端 AI 最大的差异点。

你会看到一个对话框:

```
┌────────────────────────────────────────┐
│ 请选择 WorkBuddy 可以访问的文件夹     │
│                                        │
│ ☑ 桌面                                │
│ ☑ 文档                                │
│ ☑ 下载                                │
│ ☐ 工作目录(需要手动指定)            │
│ ☐ 其他常用目录(可继续添加)          │
│                                        │
│        [ 选择文件夹 ]  [ 确定 ]         │
└────────────────────────────────────────┘
```

**WorkBuddy 的设计原则:只能访问你明确授权的文件夹**。默认勾选的是"桌面/文档/下载"三个用户目录(Windows 自带)。你也可以点"选择文件夹"添加自己的工作目录,比如 `D:\WorkBuddy_workspace\`。

**为什么文件夹授权这么重要?**

想象一下,WorkBuddy 帮你读邮件、读 Excel、读 PDF、写 PPT——它必须能访问你电脑上的文件。但**如果你授权它读"整个 C 盘"**,那它就过度授权了——它能读到你的浏览器历史、系统文件、其他应用的配置,这些都不是你想要的。

**最小授权原则**(Principle of Least Privilege):只授权 WorkBuddy 访问"你工作需要的那个目录"。

**实用建议**:
- 如果你的工作文件都在 `D:\WorkBuddy_workspace\` 这种专门目录 → 只授权这一个目录
- 如果你的工作文件分散在桌面/文档/下载 → 默认勾选的就够
- 如果你不确定 → 先默认勾选,等用熟了再调整(随时可以在"设置 → 权限"里改)

点"**确定**"完成文件夹授权。

### 步骤 7:登录 WorkBuddy

接下来是登录页面。WorkBuddy 支持三种登录方式:

| 方式 | 适合 | 操作 |
|---|---|---|
| **手机号** | 首次使用、个人账号 | 输入手机号 → 收短信验证码 → 输入 → 登录 |
| **微信扫码** | 国内最常用,推荐 | 弹出二维码 → 微信扫一扫 → 确认授权 → 登录 |
| **邮箱** | 海外用户、不用微信的同事 | 输入邮箱 → 收邮件链接 → 点击链接 → 登录 |

**推荐用微信扫码**:最方便,不用记密码,登出后再登录也快。

登录成功后,WorkBuddy 主页会出现,展示三栏布局——这是第 3 章的内容,本章先到此为止。

## 2.3 macOS 安装流程(5 分钟)

macOS 的安装流程跟 Windows 大同小异,但有几个 macOS 特有的坑需要注意。

### 步骤 1:下载并打开 dmg

下载 `WorkBuddy-x.x.x.dmg`(约 480 MB)后,双击挂载。挂载后会出现一个窗口,左边是 WorkBuddy 图标,右边是 Applications 文件夹快捷方式。

> **避坑:不要用 Safari 之外的浏览器下载**
>
> 部分第三方浏览器(比如某些国内浏览器)下载 dmg 文件可能损坏,导致安装时提示"无法打开"。如果遇到,**用 Safari 重新下载**。

### 步骤 2:拖拽安装

把左边的 WorkBuddy 图标**拖拽**到右边的 Applications 文件夹。等待 5-10 秒(可能要求输入 macOS 账户密码)。

### 步骤 3:启动 WorkBuddy

打开"启动台",找到 WorkBuddy 图标,点击启动。

### 步骤 4:绕过 Gatekeeper 警告

**这是 macOS 特有的坑**。macOS 默认会拦截"未在 App Store 上架"或"未使用 Apple 开发者证书签名"的应用,弹窗"无法打开,因为它来自身份不明的开发者"。

如果你看到这种弹窗,**不要慌**:

1. 打开"**系统设置** → "**隐私与安全性**""
2. 向下滚动,找到"**安全性**"部分
3. 你会看到一行"**WorkBuddy 已被阻止使用**",右边有"**仍要打开**"按钮
4. 点击"**仍要打开**"
5. 系统再次弹窗确认"是否打开",点"**打开**"

之后 WorkBuddy 就可以正常启动了。**这个过程只发生在第一次**,以后 macOS 会记住你的选择。

> **如果 Gatekeeper 警告更严格**(比如"无法打开,因为它来自身份不明的开发者"):
>
> 打开"终端",输入:
>
> ```bash
> sudo xattr -dr com.apple.quarantine /Applications/WorkBuddy.app
> ```
>
> 输入密码,执行后即可正常启动。
>
> 这一步的原理:macOS 给从网络下载的应用打了"quarantine"标记(隔离),`xattr` 命令清除这个标记。

### 步骤 5:文件夹授权 + 登录

跟 Windows 完全一致(见 2.2 步骤 6-7)。

### 步骤 6:macOS 权限授予

macOS 跟 Windows 不同的是,**macOS 应用要访问某些功能需要单独授权**。WorkBuddy 首次启动时,会弹窗申请以下权限:

| 权限 | 用途 | 是否必须 |
|---|---|---|
| **文件和文件夹访问** | 读你授权的目录 | ✅ 必须(否则读不了文件) |
| **完全磁盘访问权限** | 读 iCloud 同步的桌面/文档 | 可选(同步文件时需要) |
| **辅助功能(Accessibility)** | 读其他应用的内容(比如邮件正文) | 可选(读邮件客户端时需要) |
| **屏幕录制** | 截图功能(第 4 章会用到) | 可选 |
| **麦克风** | 语音输入 | 可选 |
| **通知** | 任务完成提醒 | 可选 |

**建议**:第一次启动时,**全部点"好"授权**。WorkBuddy 是本机应用,这些权限不会传出本机,只是用来让你更高效地工作。如果你某项点"拒绝",WorkBuddy 那部分功能就用不了,你可以事后在"系统设置 → 隐私与安全性"里重新授权。

## 2.4 安装完成后的第一次任务

登录成功后,WorkBuddy 主页会出现。**我们先跑通一个最简单的任务,确认安装成功**。

### 测试任务:"读我刚下载的 PDF,告诉我它讲什么"

**步骤**:

1. 在三栏布局的左栏顶部,找到"**+ 新建任务**"按钮,点击
2. 在中栏输入框,输入下面的提示词:

```
请读取我授权目录下的所有 PDF 文件(通常是 ~/Documents/WorkBuddy 测试/ 或你授权的任意位置),
挑出最近修改的 1 个,用 200 字告诉我它讲什么。
```

3. 顶部下拉框,**确认模型选择是"自动(多模型路由)"**(默认设置)
4. 点击右下角的"**提交**"按钮

WorkBuddy 会显示"思考中……",几秒到几十秒后,中栏会出现 AI 的回复。

**如果成功**:
- AI 会告诉你"我找到了文件 X.pdf,它是关于 Y 的内容……"
- 同时,右栏的"文件"标签页会显示这个 PDF 的缩略图
- 左栏的"历史任务"会记录这条任务

**如果失败**(常见原因及解决):

| 错误提示 | 原因 | 解决 |
|---|---|---|
| "无法访问任何文件" | 文件夹授权没成功 | 设置 → 权限,重新授权 |
| "模型调用失败" | 联网问题或模型服务临时不可用 | 检查网络,或换"手动选择模型"试 |
| "文件不存在" | 测试 PDF 还没放到授权目录 | 把任意 PDF 复制到授权目录 |
| "Credits 不足" | 免费 Credits 用完了 | 充值(见第 7 章) |

**如果一切正常**:恭喜你,WorkBuddy 已经装好了,可以进入第 3 章学习主界面。

## 2.5 常见安装问题排查

### Q1:安装包下载后打不开(Windows)

**现象**:双击 .exe 后,弹窗"此应用无法在你的电脑上运行"或"Windows 已保护你的电脑"。

**解决**:
1. 检查系统版本:WorkBuddy v1.0 需要 Windows 10 1809 或更新版本(包括 Windows 11)
2. 检查下载完整性:右键下载的 .exe → "属性" → 看"数字签名"是否正常。如果显示"未知",说明下载损坏,重新下
3. 关掉杀软临时测试:360 / 腾讯管家 / 火绒可能误拦。临时退出杀软,看能不能装。如果可以,把 WorkBuddy 加入白名单

### Q2:安装后启动,白屏或闪退(Windows)

**现象**:装好了,点桌面图标,启动几秒后白屏或自动关闭。

**解决**:
1. 检查 .NET Framework:WorkBuddy 需要 .NET Framework 4.8 或更新版本。Windows 10 1809+ 默认带;如果你的系统更老,先升级 .NET
2. 检查显卡驱动:WorkBuddy 用了 WebView2 渲染(类似 Chrome 内核)。如果显卡驱动过旧,可能白屏。更新显卡驱动
3. 查看日志:`%AppData%\WorkBuddy\logs\` 下找 `crash.log`,看错误信息

### Q3:macOS 装好了,但启动后提示"文件损坏"

**现象**:拖拽安装到 Applications,启动后 macOS 弹窗"WorkBuddy 损坏,无法打开"。

**解决**:这是 Gatekeeper 的"quarantine 标记"问题。在终端执行:
```bash
sudo xattr -dr com.apple.quarantine /Applications/WorkBuddy.app
```
输入密码即可。这条命令会清除"从网络下载"标记,让 macOS 信任这个应用。

### Q4:文件夹授权窗口打不开 / 闪退

**现象**:首次启动,文件夹授权窗口出现后立刻消失。

**解决**:
1. 重启 WorkBuddy 再试
2. 如果还不行,跳过首次授权:关掉 WorkBuddy → 手动编辑 `~/Library/Application Support/WorkBuddy/config.json`(macOS)或 `%AppData%\WorkBuddy\config.json`(Windows)→ 添加 `{"authorizedFolders": ["你想要的目录"]}` → 重启

### Q5:登录后看到"试用版"标识,无法用全部功能

**现象**:登录后,顶部显示"试用版 7 天",部分功能(比如多模型路由)不可用。

**解决**:
- 试用版能用 80% 功能。完整功能需要订阅 Pro 版(99 元/月,见第 7 章)
- 或者联系 WorkBuddy 客服申请延长试用

## 2.6 升级 WorkBuddy 到最新版

WorkBuddy 大约每 2-3 个月发布一个新版本。升级方式:

**自动升级(推荐)**:WorkBuddy 启动时会自动检查更新。如果有新版本,会弹窗提示"发现新版本 v1.2,是否升级?"。点"立即升级"即可,无需重新下载安装包。

**手动升级**:从官网下载最新版安装包,直接运行。WorkBuddy 会检测已有安装并自动覆盖,你的配置、授权文件夹、历史任务都会保留。

> **避坑:不要在公司内网环境下强制升级**
>
> 部分公司内网会拦截 WorkBuddy 的更新检查请求。如果发现 WorkBuddy 启动时长时间卡在"检查更新",可以在"设置 → 高级"里关掉"自动检查更新",让 IT 部门在白名单里放行后再开。

## 2.7 卸载 WorkBuddy

如果哪天你不想用 WorkBuddy 了,卸载方式:

- **Windows**:"设置 → 应用 → 搜索 WorkBuddy → 卸载"。卸载时会问你"是否保留授权文件夹配置?",一般选"否",完全清理
- **macOS**:"应用程序" → 把 WorkBuddy 拖到废纸篓。彻底删除(包括配置)在终端执行:
  ```bash
  rm -rf ~/Library/Application\ Support/WorkBuddy
  rm -rf ~/Library/Preferences/com.WorkBuddy.plist
  ```

卸载后,你的文件不会被删除(WorkBuddy 只读不写),授权文件夹配置也只删 WorkBuddy 自己的部分。

本章我们讲了 WorkBuddy 的完整安装流程:

1. **下载**:只从官网下载,不要用第三方下载站;根据操作系统和芯片选对版本

- ✅ WorkBuddy 桌面图标在

- ✅ 微信扫码登录成功
- ✅ 至少授权了一个工作目录
- ✅ 跑通 1 个简单任务(读 PDF 总结)

如果这些都过了,你可以进入第 3 章。如果有问题,先看 2.5 节的问题排查。
