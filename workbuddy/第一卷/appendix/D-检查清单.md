# 附录 D 检查清单

> 本清单用于在读完第一卷后,做一次自检。也可作为团队推广前的内部 checklist。

## 第一卷核心动作清单

### 装上 WorkBuddy(第 2 章)

- [ ] 已下载并安装 WorkBuddy(Win 11 / macOS 14+)
- [ ] 已选择登录方式(微信 / 企业微信 / 手机号)
- [ ] 已建立独立工作目录(非系统盘,例如 `D:\WorkBuddy_workspace`)
- [ ] 已最小化授权(只授权工作目录,未授权桌面、文档、下载)
- [ ] 已解决首次启动的所有弹窗(macOS 验证、Defender 拦截等)

### 熟悉主界面(第 3 章)

- [ ] 能用左栏的"新建任务"创建任务
- [ ] 能在中栏输入框里输入、拖文件、贴截图
- [ ] 能在右栏看到 Credits 消耗、Skill 加载、模型选择
- [ ] 已熟悉至少 3 个常用快捷键

### 用熟 5 个场景(第 4 章)

- [ ] 周报:已用真实素材生成过 1 份周报
- [ ] 汇报:已用真实素材生成过 1 份汇报材料
- [ ] 邮件:已翻译过 1 封真实商务邮件
- [ ] 纪要:已整理过 1 份会议纪要
- [ ] PPT:已生成过 1 份 PPT 大纲

### 掌握"派活型"提示词(第 5 章)

- [ ] 已重写过至少 3 个旧提示词,使用"目标 / 约束 / 输出"三件套
- [ ] 已沉淀至少 1 个"标准提示词 v1"
- [ ] 已知提示词能写什么、不能写什么

### 理解 Skill(第 6 章)

- [ ] 已从技能市场试用并加载 3 个 Skill
- [ ] 已把 1 个标准提示词按 Skill 格式写过(可不发布)
- [ ] 已识别出团队里 3 个最值得封装为 Skill 的提示词

### 算清成本(第 7 章)

- [ ] 已知过去一周的 Credits 消耗总量
- [ ] 已按任务类型分桶消耗数据
- [ ] 已测算月消耗,选择合适的付费方案(免费 / Pro / Ultra / 自购 API)
- [ ] 已评估哪些任务适合自购 API Key

### 准备推向团队(第 8 章)

- [ ] 已完成 10 题自检清单
- [ ] 已选 3 个最重要的"成功要素",写具体执行方案
- [ ] 已与 1-2 位同事讨论过本章内容,获得反馈

## 阶段门槛

| 阶段 | 通过条件 | 下一阶段 |
|---|---|---|
| **装好** | 装上并完成首次启动 | 开始探索主界面 |
| **会用** | 完成 5 个场景中的 3 个 | 掌握提示词工程 |
| **用熟** | 沉淀 3 个标准提示词,日均 5+ 次使用 | 准备推向团队 |
| **可推** | 完成 10 题自检清单,有 3 个试点场景 | 进入第二卷 |

## 不通过怎么办

- **"装不上"**:回到第 2 章,排查系统兼容性、杀毒软件、网络环境
- **"用了但没感觉"**:回到第 4 章,选 2-3 个与你真实工作最相关的场景重做
- **"提示词写不好"**:回到第 5 章"提示词的迭代方法",跑两轮迭代
- **"不知道团队推不推"**:先找 1-2 个愿意试的同事,做 30 天小范围试点(详见第二卷第 7 章)
