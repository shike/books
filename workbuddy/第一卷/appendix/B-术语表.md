# 附录 B 术语表

> 本术语表覆盖三卷书,本卷首发。后续卷新增术语将增量更新。

## A

**API Key**
应用程序编程接口密钥,用于访问大模型服务的凭证。在 WorkBuddy 中,自购 API Key 可让任务走用户自己的模型,不消耗平台 积分。

**自动化(Automation)**
WorkBuddy 中的功能,允许设置触发条件(如定时、文件变化),让 WorkBuddy 自动执行任务。

## B

**本机(本地)**
指用户自己的电脑。WorkBuddy 与 ChatGPT 等云端 AI 的根本差异之一是部署在本机,可直接读写本地文件。

## C

**Claw**
WorkBuddy 的远程控制功能,通过企业微信向 WorkBuddy 发送任务(详细见第二卷第 2 章)。

**积分(积分)**
WorkBuddy 的资源计量单位。完成任务消耗 积分,通过注册、签到、付费或自购 API Key 获取。

**插件 / Skill**
见 Skill。

## D

**对话框 / 对话区**
WorkBuddy 主界面中间区域,用户与 WorkBuddy 交互的场所。

**登录方式**
WorkBuddy 支持三种登录:微信扫码(个人)、企业微信(团队)、手机号(兜底)。

## E

**Expert Center / 专家中心**
WorkBuddy 中沉淀团队最佳实践的功能入口(详细见第二卷第 5 章)。

## F

**Folder Permission / 文件夹授权**
WorkBuddy 启动时要求用户授予本地文件夹读取权限。授权范围应遵循"最小授权原则"。

## G

**工作目录(Workspace)**
WorkBuddy 可访问的本地文件夹。建议建立独立目录(非系统盘)统一管理 AI 相关文件。

## H

**Hint / 提示词(Prompt)**
用户与 WorkBuddy 沟通的自然语言指令。详见第 5 章。

## K

**积分 套餐**
付费方案:Pro 版 99 元/月含 50,000 积分,Ultra 版 299 元/月含 200,000 积分。

## M

**Model / 模型**
WorkBuddy 底层调用的大语言模型。不同模型档位的 积分 消耗不同。

## P

**派活型提示词**
管理者视角的提示词写法:目标 / 约束 / 输出三件套。详见第 5 章。

**Pro 版 / Ultra 版**
见 积分 套餐。

**Prompt**
见 提示词。

## Q

**企业微信**
WorkBuddy 的团队登录方式之一。绑定后可启用 Claw 远程控制。

## S

**Skill / 技能**
WorkBuddy 中可复用的功能包,把提示词、文件处理逻辑、输出格式封装为可被反复调用的工具。详见第 6 章(概念)、第三卷第 2 章(开发)。

**Skill 市场 / 技能市场**
WorkBuddy 内浏览和加载现成 Skill 的入口。

**审计**
WorkBuddy 在右侧工具面板提供操作日志,管理者可用于追溯 AI 的输入输出与文件操作。

## W

**Workspace**
见 工作目录。

**WorkBuddy**
本书主题:国产桌面端 AI 客户端(具体版本、定价、功能边界以你购买本书时 WorkBuddy 官方公告为准,撰写时为 2026 年 8 月),运行于 Windows 与 macOS。

## X

**项目符号 / 列表 / 模板**
详见附录 C。

## Y

**月度访问量**
截至 2026 年 6 月,WorkBuddy 月访问量为 2097 万次,国内 PC 端 AI 原生办公类应用规模第一(数据来源:产品方公开数据)。

## Z

**自购 API Key**
用户自行购买大模型 API Key,接入 WorkBuddy 后,任务走自购模型,不消耗平台 积分。

**自动化**
见 自动化(Automation)。
