# 附录 C 提示词模板集(第一卷)

> 本附录收录第一卷涉及的 15 个常用提示词模板,按场景组织。每个模板给"完整版 + 简化版"两个版本。

## 1. 周报整理

### 完整版

```
基于以下本周工作素材,整理一份周报。

要求:
- 输出三部分:已完成事项、进行中事项、下周计划
- 每条事项 1-2 句话,简洁具体
- 关键数据要保留数字
- 语气客观克制,不夸大成绩

[在此粘贴本周素材:会议纪要、邮件往来、聊天记录、文件摘录等]
```

### 简化版

```
整理以下素材为周报:已完成 / 进行中 / 下周计划,每条 1-2 句。

[素材]
```

## 2. 汇报材料生成

### 完整版

```
基于以下材料,生成一份 [时长:5 分钟] 的汇报材料,受众是 [受众角色:部门全员 / 高管 / 客户]。

要求:
- 结构:背景 / 进展 / 关键数据 / 下一步 / 风险
- 关键数据用数字,不要"很多"、"大幅"等模糊词
- 长度控制在 [字数] 字以内
- 语气:正式但不生硬

[材料]
```

## 3. 英文邮件翻译

### 完整版

```
将以下中文邮件翻译为英文。

约束:
- 语气:正式但不生硬,适用于初次合作的客户
- 首尾礼貌,符合商务规范
- 关键专有名词首次出现给中英对照
- 不直译,保持商务得体性

[中文邮件正文]
```

## 4. 会议纪要结构化

### 完整版

```
将以下会议记录整理为结构化纪要。

输出三部分:
- 关键结论(3-5 条 bullet)
- 行动项(按责任人 + 截止时间组织)
- 待讨论议题(列出但不强求结论)

[会议记录 / 录音转写]
```

## 5. PPT 大纲生成

### 完整版

```
基于以下信息,生成一份 [N] 页的 PPT 大纲。

- 主题:[主题]
- 受众:[受众]
- 关键论点:[3-5 个]
- 风格:[数据型 / 故事型 / 论证型]
- 时长:[总时长]

每页输出:标题、核心要点(2-3 条)、建议时长。
```

```
3. 异常与建议(1-3 条)

[Excel 文件路径]
```

```
[方案描述]
```

```
[客户邮件]
```

## 15. 自我学习

### 完整版

```
我想学习 [主题]。

当前水平:[小白 / 入门 / 中级]

请帮我:
1. 推荐 3 个核心概念先掌握
2. 给 1 个最小可执行练习
3. 列出常见误区
```

## 使用建议

- **不要照搬**:模板只是起点,根据你的真实场景调整
- **迭代优化**:第一次跑出来的提示词不满意,加约束再来
- **沉淀复用**:被反复使用的提示词,固定下来作为你的"标准提示词"
- **团队共享**:优秀的提示词应该是团队资产(详见第二卷第 5 章)
