# 附录 E 案例库(第一卷)

> 本附录收录 2-3 个真实管理者使用 WorkBuddy 的案例。素材来自访谈与脱敏处理,所有数据已脱敏。

> **状态**:待补充。第一卷完稿前需完成 2-3 个案例访谈。

## 案例征集方向

- **案例 1:中层管理者(部门负责人级别)**
  - 行业:互联网 / SaaS
  - 团队规模:5-15 人
  - 重点场景:周报 / 汇报材料 / 跨部门沟通
  - 期望产出:从"AI 旁观者"到"日常使用者"的转变过程

- **案例 2:HR / 培训负责人**
  - 行业:传统企业(制造 / 零售)
  - 团队规模:50-200 人
  - 重点场景:培训内容生成 / 制度文档整理
  - 期望产出:团队级 AI 推行的真实障碍

- **案例 3:业务负责人(销售 / 运营)**
  - 行业:to B 服务
  - 团队规模:10-30 人
  - 重点场景:客户邮件 / 方案撰写 / 数据分析
  - 期望产出:从个人到团队的可复制路径

## 案例模板

每个案例按以下结构写:

```markdown
## 案例 N:[案例标题]

### 背景
- 行业 / 团队规模 / 管理者角色
- 引入 WorkBuddy 前的状态

### 引入过程
- 第一次接触的时间与场景
- 推动落地的关键决策
- 遇到的阻力与解决

### 实际使用
- 1-3 个真实场景的展开(输入 / 提示词 / 输出 / 反思)
- 积分 消耗与成本数据
- 团队反馈

### 经验与教训
- 关键收获
- 走过的弯路
- 给其他管理者的建议

### 截至日期
- 数据 / 截图 / 引用截至 [日期]
```

## 案例素材来源

- 公开演讲与分享
- 行业访谈(计划在第一卷完稿前完成 5-10 个访谈)
- 用户调研(需配合产品方)
