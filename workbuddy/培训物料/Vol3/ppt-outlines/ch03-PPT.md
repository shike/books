## Slide 4 — API Key 是什么:不止"省钱"
- 三个真正改变的事:
  - **模型选择权**:在 其他主流闭源模型 / 主流闭源模型 / DeepSeek 之间自由切换
  - **成本可观测**:每条对话对应到具体 token,黑盒变明盒
  - **数据流向清晰**:走你和厂商的直连链路,WorkBuddy 仅中转
- 一句话:API Key 是控制权,不是折扣券
- 配图:`figures/3.3.1-api-flow.png`

## Slide 5 — 风险载体:Key 泄露=钱被刷光
- 真实案例:GitHub 公开仓库 Key 几小时被刷数千美元
- 强制习惯:**Keychain 集成**——存到操作系统级(macOS Keychain / Windows Credential Manager)
- 明文配置 = 裸奔;Key 一旦泄露立即吊销+轮换
- 收束:省小钱丢大钱的反面教材
- 配图:`figures/3.3.4-model-config.png`(配置入口)

## Slide 6 — 自购 API 的成本边界
- 订阅制 vs 按量计费,不是绝对谁便宜
- 三档用量判断:
  - 月对话 < 3000 次(短问答为主):标准版 ¥70/月封顶
  - 月对话 5000-20000 + 长文档:旗舰版 ¥83/月(年付)性价比最高
  - 月对话 > 2 万或需 其他主流闭源模型/Opus:自购 API 进入划算区间
- 关键提醒:**重量任务比轻量任务贵 100-1000 倍**——别让 其他主流闭源模型 做翻译
- 配图:`figures/3.3.2-cost-comparison.png`(成本对比)

## Slide 7 — 隐性成本与常见坑
- 隐性成本:监控余额、对比折扣、处理 Key 失效——每月 1-2 小时
- 三大新手坑:
  - **超额扣费**:批量任务瞬秒余额,设单日熔断
  - **汇率/税费**:美元 API 实际成本比表观高 5-10%
  - **版本更新**:厂商每 2-3 月调价,季度浏览价格页
- 配图:`figures/3.3.6-cost-perf-balance.png`(成本性能天平)

## Slide 8 — 多模型策略:任务分级 + 模型分级
- 核心思想:**用对的模型做对的事**
- 三档分级:
  - **轻量**(翻译/改写/格式转换):其他主流闭源模型-mini / Haiku,单次 0.004 元
  - **中量**(摘要/结构化分析/邮件):其他主流闭源模型 / Sonnet,单次 0.1 元
  - **重量**(复杂代码/数学证明/创意):其他主流闭源模型 / Opus,单次 1-5 元
- 务实做法:建"默认分级",只在明显简单/复杂时主动指定
- 配图:`figures/3.3.3-multi-model.png`(多模型策略示意)

## Slide 9 — 案例:产品经理 30 份用户调研
- 工作流拆三段:
  - 其他主流闭源模型-mini 翻译 30 份原始记录(轻量)
  - 其他主流闭源模型 合并趋势报告(中量)
  - 其他主流闭源模型 提炼三个关键洞察(重量)
- 成本:总成本 ≈ 全部走 其他主流闭源模型 的 1/3
- 一句话:多模型策略的威力,**不靠更聪明,而靠更合理**
- 来源:第三卷 §3.3,L104-108

## Slide 10 — 模型版本号陷阱
- 其他主流闭源模型厂商 / 其他主流闭源模型厂商 每 2-3 月发新模型,价格能力都变
- 你的 API Key 指向具体版本(如 gpt-4o-2024-08-06)
- 操作:**版本锁定** + 每次发版花 15 分钟跑典型任务集评估
- 警惕"温水煮青蛙"——悄悄降质几周你才发现

## Slide 11 — 四步配置流程(上)
- 步骤 1:右上角头像 → 设置 → 模型与 API
- 步骤 2:添加新供应商,填 Key + 起易记别名(避免"我的 其他主流闭源模型"和"备用 主流闭源模型"搞混)
- 步骤 3:每个工作目录设"默认模型 + 备选模型"
- 步骤 4:对话级切换——输入框右侧下拉,临时切换不改变默认

## Slide 12 — 四步配置流程(下)+ 工程习惯
- 别名语义化:其他主流闭源模型厂商-GPT4o vs Azure-GPT4o,计费主体不同
- 余额预警:20% + 5% 两档阈值,提前充值
- 90 天轮换 Key:加新→切默认→观察 24h→删旧
- 应急备忘:供应商/创建日期/用途/续费方式——**存 WorkBuddy 工作目录之外**
- 故障排查 4 步:用量面板余额 → 官网红条 → 诊断工具 → 切备选验证

## Slide 13 — 提示词级强制路由
- 进阶技巧:在提示词开头显式指定模型
- 三个示例(给学员示范):
  - "使用 其他主流闭源模型 回答。"
  - "请用 其他主流闭源模型-mini 即可,不需要长推理。"
  - "请对比 其他主流闭源模型 和 其他主流闭源模型 在这道题上的答案差异。"
- 一句话:把多模型策略从手动升级为半自动

## Slide 14 — 不被单一厂商绑定
- 三次历史单点故障:季度涨价 30% / 合规暂停对华服务 / 升级后质量下滑
- **温水煮青蛙**:某版本升级后变"礼貌",长文档能力悄悄下降
- 解法:同工作目录接 2-3 家厂商,加 1 家国产做兜底
- 隐性收益:**谈判筹码**——同时接四家,某次续约拿到 30% 折扣(章节 §3.5,L178)
- 配图:`figures/3.3.5-vendor-agnostic.png`(架构去锁定)

## Slide 15 — 任务路由:把策略落地
- 在 WorkBuddy 高级设置里预设:
  - 代码任务 → 主流闭源模型
  - 文档任务 → GPT
  - 敏感数据 → 国产合规模型
- 切勿频繁切换:稳定使用 1-2 家主力,切换是"消防演习"
- 季度对比测试:同任务跑 2-3 家,记质量/速度/成本
- 数据合规:跨境业务数据走海外 API 可能违反 个人信息保护相关法规/DSL,合规 > 能力

## Slide 16 — 决策口诀与角色差异
- 口诀:**轻量优先、重型慎用、长期看账单**
- 三类角色平衡:
  - **个人**:成本权重调高,够用就好
  - **小团队**:建立 1-2 页"模型使用规范",降低决策成本
  - **企业**:稳定 > 合规 > 单价,单次故障损失 > 全年 API 价差
- 来源:第三卷 §3.6,L200-204

## Slide 17 — 月度复盘三问
- 在"用量面板"按"任务类型 × 模型"交叉对比,问自己:
  1. 这个任务用更便宜的模型能完成吗?
  2. 这个任务用更强的模型能明显提升质量吗?
  3. 这个任务根本不需要 AI 吗?
- 第三个问题最值钱:很多任务用脚本/规则/人工更划算
- 坚持半年,通常省 30%+ 成本,质量不降反升

## Slide 18 — 用量档位推荐配置
- **月消耗 0-500 元**:订阅标准版 ¥70/月封顶,不建议自购
- **月消耗 500-3000 元**:旗舰版 ¥83/月(年付) + 少量强模型 API,混合模式
- **月消耗 3000-10000 元**:自购 API 为主 + 旗舰版做备用底 + 2-3 家厂商任务路由
- **月消耗 10000+**:自购 + 商务合约 + 多区域容灾,需专职人员
