# WorkBuddy 全天工作坊(8 小时含午休)

> 适用:客户深度内训,完整 1 阶认证预备班
> 目标:让学员带走 **1 套团队工作目录 + 3 个自定义 Skill + 1 张 30 天路线**
> 人数:15-25 人(按 5-6 人/组,3-5 组)
> 必备:WorkBuddy 现场版、投影、白板、便利贴、行动卡模板、午餐
> 讲师配比:主讲师 1 + 巡场助教 2-3

## 课前 1 周准备清单

### D-7:内容
- 确认 24 份模块卡(本流程对应)已发到学员群
- 提前 3 天发"工作坊预习包":Vol1-01/02/03 模块卡 + 附录 A 安装速查
- 行动卡模板(30 天日历、L1/L2/L3 自检、ROI 计算表)定稿并打印

### D-3:账号与现场
- WorkBuddy 演示账号 + 学员账号(15-25 个)开通、绑定企业微信 corp_id
- 投影测试(主屏+侧屏)+ 网络测试(主备两路 Wi-Fi)
- 便利贴(3 色:绿期待/红痛点/黄行动)、白板笔(黑/红/蓝各 3 支)、计时器
- 学员手册(打印)+ 笔记本 + 笔
- 午餐(15-25 份)+ 茶歇 2 次(咖啡、茶、点心)
- 教室布置:5-6 张圆桌(每桌 4-5 人)+ 主讲台 + 白板墙

### D-1:讲师对齐
- 助教对齐 3 个角色:巡场答疑、计时提醒、截图收集
- 3 套应急预案演练:断网、账号未到、学员卡住
- 5 名标杆学员(种子用户)事先沟通,午休前完成 Skill #2 框架

---

## 现场应急预案

| 突发情况 | 处置 |
|---|---|
| 网络断 | 切换到本地演示视频(已 D-1 下载)+ 离线模式跑本地任务 |
| 学员账号未到 | 讲师账号共享屏幕演示,助教现场用邀请码兜底开通 |
| 学员卡住 | 小组互助优先 → 巡场助教 → 主讲师 1v1(最多 3 分钟,超时挂"待办墙") |
| 时间超时 | 优先级:砍"学员互评"5 节点决策树 → 砍茶歇 → 砍合影;30 天行动卡必保 |
| 学员严重跑题 | 主讲师插话收回节奏,记入"待办墙",课后再答 |
| 设备故障 | 备用笔记本 + HDMI 线 + 投影仪备用灯泡 |

## 课后 1 周跟进

### D+1
- 群发"今日演示的提示词模板"PDF(对应 Vol1-05 三件套 + 7 项自检)
- 群发"30 天行动卡"模板(对应 Vol2-07 附录 D 清单 7)
- 邀请加入 30 天落地群(可承接为第二阶段"90 天路线")

### D+3
- 群发"团队工作目录建立检查表"(对应 Vol2-03 附录 D 清单 3)
- 群发"3 个 Skill 的发布与版本号管理"小贴士(对应 Vol3-02)

### D+7
- 第 7 天群内答疑 1 次(1 小时,主讲师在线)
- 收集"3 件事"进展:工作目录用了没、3 个 Skill 跑了几次、30 天卡打到 Day 几

### D+30
- 阶段性复盘会(2 小时,线上):用 Vol2-08 月度复盘五问
- 决定是否进入"推广期"还是"回炉补 L1"
