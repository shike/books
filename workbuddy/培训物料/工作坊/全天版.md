# WorkBuddy 全天工作坊(8 小时含午休)

> 适用:客户深度内训,完整 1 阶认证预备班
> 目标:让学员带走 **1 套团队工作目录 + 3 个自定义 Skill + 1 张 30 天路线**
> 人数:15-25 人(按 5-6 人/组,3-5 组)
> 必备:WorkBuddy 现场版、投影、白板、便利贴、行动卡模板、午餐
> 讲师配比:主讲师 1 + 巡场助教 2-3

## 现场应急预案

| 突发情况 | 处置 |
|---|---|
| 网络断 | 切换到本地演示视频(已 D-1 下载)+ 离线模式跑本地任务 |

## 工作坊练习题库(讲师可直接照做)

> 全部 17 题覆盖第一卷全 8 章 + 第二卷 5 章(M03/M04/M05/M07/M08);每题给"时长 / 人数 / 道具 / 步骤 / 评分"五要素;讲师按时间表空闲段位中调用

### 练习 01:工作坊契约共建(暖场)

- **时长**:10 min
- **人数**:5-6 人/组,3-5 组
- **道具**:便利贴、白板、白板笔
- **步骤**:
  1. 讲师引导每组"3 期待 + 1 痛点"(绿期待/红痛点便利贴)
  2. 讲师列 5 条工作坊规则,全组口头同意(例:手机静音 / 按时回座 / 卡住先问同伴 / 提问不评判 / 行动卡必填)
  3. 各组派 1 位代表念 1 条最严的规则
  4. 讲师把全组最严的 3 条规则写到白板"契约栏"
- **评分**:3 期待 + 1 痛点收集率 100%;契约规则 ≥ 5 条全员接受
- **对应模块**:Vol1-01 + Vol2-01

### 练习 02:握手测试(安装自检)

- **时长**:10 min
- **人数**:1 人 1 账号
- **道具**:WorkBuddy 学员账号、客户端、投影
- **步骤**:
  1. 讲师演示握手测试 1 次(打开 → 登录 → 新建任务 → 看到回复)
  2. 学员在 5 min 内独立完成
  3. 助教收"通过"截图
  4. 未通过者挂"待办墙",课前 1v1 帮兜底
- **评分**:通过率 ≥ 95%;未通过者课后 1v1 兜底 100%
- **对应模块**:Vol1-02

### 练习 03:工作目录搭建(三决策落地)

- **时长**:15 min
- **人数**:1 人 1 目录
- **道具**:Win 11 / macOS 14+ 文件管理器、路径模板
- **步骤**:
  1. 讲师演示"三决策"(下载/登录/授权)的目录落点:`D:\WorkBuddy_workspace\` 或 `~/WorkBuddy_workspace/`
  2. 学员各自建目录,贴 1 段示例对话文件进去
  3. 学员在 WorkBuddy 中"派活→选素材"走通 1 次(选自己刚贴的文件)
  4. 助教截图存档"工作目录现状"
- **评分**:目录路径规范 100%;首跑通 100%
- **对应模块**:Vol1-02 + Vol2-03

### 练习 04:5 步派活流程

- **时长**:15 min
- **人数**:1 人 1 任务
- **道具**:学员账号、3 段示例对话文本
- **步骤**:
  1. 讲师讲"5 步派活":打开 → 输入角色 → 贴素材 → 加约束 → 派活
  2. 学员用一段自己的真实对话,按 5 步跑通
  3. 学员自查"5 步是否都到位"——缺哪步就补
  4. 助教巡场答疑
- **评分**:5 步全到位 ≥ 90%;跑通率 ≥ 85%
- **对应模块**:Vol1-03

### 练习 05:5 大场景实操 1 选 1

- **时长**:20 min
- **人数**:1 人 1 场景
- **道具**:5 大场景提示词骨架表
- **步骤**:
  1. 讲师发 5 大场景(周报/汇报/邮件/纪要/PPT 大纲)骨架表
  2. 学员选 1 个最痛场景,用真实素材 + 骨架,跑 1 次完整任务
  3. 学员记录耗时与 积分 消耗
  4. 学员把"AI 哪里不对"列 1 张便利贴贴白板
- **评分**:骨架套用 100%;跑通率 ≥ 85%;1 张便利贴 ≥ 1 句可操作改进
- **对应模块**:Vol1-04

### 练习 06:三件套提示词改写 v1

- **时长**:20 min
- **人数**:1 人 1 场景
- **道具**:便利贴、白板
- **步骤**:
  1. 讲师教"目标+约束+输出"三件套 + 7 项自检
  2. 学员用五元素改写上周真实素材,跑 1 轮
  3. 学员记录"AI 哪里不对"
  4. 学员按 7 项自检打分
- **评分**:三件套完整度 ≥ 90%;7 项自检 ≥ 5 项打勾
- **对应模块**:Vol1-05

### 练习 07:提示词 v1→v2 迭代

- **时长**:15 min
- **人数**:1 人 1 文档
- **道具**:练习 06 的便利贴、笔记本
- **步骤**:
  1. 学员把练习 06 的便利贴"AI 哪里不对"翻译成 1 条 v2 改进
  2. 学员改写提示词为 v2,再跑 1 次
  3. 学员对比 v1 vs v2,记录"v2 改进了哪 1 句"
  4. 助教抽 3-5 位现场念 v1→v2 差异
- **评分**:v2 改进条数 ≥ 1;v2 跑通率 ≥ 85%;v1→v2 差异 1 句可讲 100%
- **对应模块**:Vol1-05

### 练习 08:周报 Skill v1 编写(从提示词到 Skill)

- **时长**:25 min
- **人数**:1 人 1 Skill
- **道具**:周报 Skill 三构成模板(触发/执行/输出)、练习 05 的素材
- **步骤**:
  1. 讲师演示"周报 Skill 四阶段进化"(个人提示词 → 团队参数化 Skill)
  2. 学员把练习 05 的提示词按 5 步流程转成 Skill(只到"识别候选 + 抽象参数")
  3. 学员用 2 段不同周报素材,各跑 1 次,确认 Skill 输出稳定
  4. 学员写下"v1 Skill 的 1 句不足",为下午的 v2 留改进点
- **评分**:三构成完整度 100%(触发/执行/输出每件至少 1 句);2 段素材跑通率 ≥ 80%
- **对应模块**:Vol1-06 + Vol1-04

### 练习 09:团队工作目录整改

- **时长**:25 min
- **人数**:5-6 人/组,1 套目录
- **道具**:团队目录样例、四段式命名表
- **步骤**:
  1. 讲师演示"公共/个人/项目"三层 + 四段式命名(项目编号_类型_日期_负责人_状态)
  2. 讲师演示"最终版.docx"失败案例,讲 R/W/S 三种权限 + `_private` 下划线前缀
  3. 学员按附录 D 清单 3 把本团队文件夹整改一遍
  4. 学员配 WorkBuddy 最小可见目录(含 `_private` 不可见)
- **评分**:三层目录 100%;四段式命名 ≥ 80% 文件;`_private` 不可见验证 100%
- **对应模块**:Vol2-03

### 练习 10:小组共写 Skill #2 团队版

- **时长**:40 min
- **人数**:5-6 人/组
- **道具**:组内分工表、Skill 三构成模板
- **步骤**:
  1. 讲师演示 1 个团队 Skill(周报汇总)从 0 到跑通的全过程
  2. 学员组内分工:1 人搭目录、1 人写三构成、1 人跑 3 个真实样本、1 人收集反馈
  3. 学员组共写 1 个团队 Skill v1(用 3 个真实输入样本验证)
  4. 学员记录"团队版 vs 个人版"的 3 个差异
- **评分**:三构成完整度 100%;3 样本跑通率 ≥ 80%;差异可讲 ≥ 3 条
- **对应模块**:Vol2-04 + Vol1-06

### 练习 11:三档互评展示(技能市场)

- **时长**:25 min
- **人数**:3-5 组抽 3-5 位展示

  4. 讲师汇总互评 Top 3 改进点,引出"提问型 vs 派活型"差距

### 练习 12:5 节点决策树演练

### 练习 14:分池订阅决策 + ROI 演练

- **时长**:20 min
- **人数**:1 团队 1 张表
- **道具**:决策表、ROI 计算表
- **步骤**:
  1. 讲师发分池订阅决策表(月消耗 < 2,000 免费 / 2,000-30,000 标准版 / 30,000-150,000 旗舰版)

### 练习 15:角色权限矩阵设计

- **对应模块**:Vol2-02 + Vol2-08

### 练习 16:Skill 版本号管理
