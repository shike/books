# 模块卡 03 — 主界面与三栏结构(WorkBuddy 的"分工说明书")

> 卷:第一卷 | 适用对象:首次使用者 | 时长:45-60 min | 难度:入门
> 配套 PPT:ch03-PPT.md | 配套附录:附录A

## 一、本模块回答的核心问题(1 句)

WorkBuddy 的左 / 中 / 右三栏各管什么、又怎么协同完成一次"派活"?

## 二、学习目标(完成后能...)

1. 准确说出三栏各自的职能(调度 / 对话 / 控制),不再"看着界面盲点"
2. 独立走完一次"新建任务 → 派活 → 检查 → 落地"5 步流程
3. 加载合适的 Skill、切换合适的模型、读懂 积分 与日志 4 类右栏信息

## 三、关键案例(2-3 个)

### 案例 1:运营总监的周报革命
- 场景:某互联网公司运营总监,周五下午做本周运营周报
- 冲突/问题:过去要翻邮件 + 翻企微 + 翻 Excel + 排版,2-3 小时都打不住
- 启示:WorkBuddy 把"体力活"(整理)做完,你只做"脑力活"(判断)。"AI 替我做表格,我看为什么指标掉了"——这是管理者用 WorkBuddy 的核心心智

### 案例 2:王总监的用户增长简报
- 场景:用户增长部门负责人,每周给 CMO 发简报(5 个数据源)
- 冲突/问题:数据源分散、人工整合易漏、版式每次都不一样
- 启示:把"5 个数据源"沉淀成可复用的指令与 Skill,每周只换素材,工作流不变(章节第 500-527 行)

### 案例 3:技能市场贪多必失
- 场景:用户为追求"全能"一次挂十几个 Skill
- 冲突/问题:WorkBuddy 反而"犹豫不决",输出变慢、积分 飙升
- 启示:一个任务 1-3 个核心 Skill,够用就好(章节第 90-96 行)

## 四、互动题(讲师在课堂上抛出的问题)

1. **开放题**:你当前工作里,哪一类任务最像"运营周报"——素材多、模板固定、每周重复?如果交给你来设计,你会把它拆成"输入素材 / 指令 / 输出"三段吗?
2. **举手投票**:你认为 WorkBuddy 三栏中,管理者最容易忽视、但长期价值最大的是哪一栏?(选项:左栏调度 / 中栏对话 / 右栏控制)

## 五、可直接用的工具/模板

- 附录A 第 A.5 节:工作目录初始化(把工作目录建在云同步盘根目录,跨设备可访问)
- 附录A 第 A.10 节:跨平台命令清单(16 条常用命令,`Ctrl/Cmd+K` 命令面板是首选)
- 第 3 章 5.3 节:5 个高频快捷键速查表(讲义最后两页,建议印成卡贴)
- 自带 Skill(若已部署):`weekly-report-skill`(周报生成)、`pdf-summarize`(PDF 摘要)

## 六、本周可做的 1 件事

挑一件你本周固定要做的事(如周报、日报、客户回邮整理),按第 3 章"5 步派活"流程跑一遍,记录耗时与 积分 消耗。下周复盘时,你就有了自己的第一份"AI 改造成本/收益账"。
