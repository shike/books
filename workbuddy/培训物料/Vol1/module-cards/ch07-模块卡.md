# 模块卡 07 — Credits 与成本(本模块回答的核心问题)

> 卷:第一卷 | 适用对象:决策者/管理者 | 时长:60 min | 难度:中阶
> 配套 PPT:ch07-PPT.md | 配套附录:附录D

## 一、本模块回答的核心问题(1 句)
**WorkBuddy 这把刀到底多贵?我能算清自己的账、选对方案、看清投入产出吗?**

## 二、学习目标(完成后能...)
1. 用三档任务分类法(简单 1-5 / 中等 20-50 / 复杂 100+)估算一次派活的 Credits 消耗
2. 在免费 / 标准版 / 旗舰版 / 自购 API 四种方案中,按月消耗区间选对自己的付费方案
3. 用"AI ROI = 节省时间 × 时薪 ÷ Credits 成本"做一次粗算,说服自己或上级

## 三、关键案例(2-3 个)
### 案例 1:某运营总监的 30% 浪费
- 场景:每周做 AI 投入产出复盘的运营总监(章节 6.2,L477-479)
- 冲突/问题:30% Credits 消耗在低价值任务上(简单问答、信息检索),只产生 10% 业务价值
- 启示:**Credits 数据的价值不是"省了多少",而是"花在刀刃上"**——释放低价值占用,转向高价值任务

### 案例 2:12 人 SaaS 团队的"分池订阅"
- 场景:某 12 人创业公司全员标准版,月花 1,188 元却 50% 用户用不满额度(附录 D.9,L146)
- 冲突/问题:一刀切订阅导致重度用户额度不够、轻度用户额度浪费
- 启示:**分池订阅**(5 重度升旗舰 + 7 轻度免费+按需)月成本看似上升,人效却提升 30%

### 案例 3:45 人 IT 部门的"本地化"降本
- 场景:某制造业 IT 部门一刀切开标准版,月花 4,455 元(附录 D.9,L148)
- 冲突/问题:60% 调用是"通用对话"——完全可以由本地小模型承担
- 启示:开启"轻量任务本地化"路由 + Skill 替代长对话,月成本降至 2,800 元,降幅 37%

## 四、互动题(讲师在课堂上抛出的问题)
1. 你过去一周的 WorkBuddy 消耗大概落在哪个区间?是 A 轻度、B 中度、还是 C 重度?(开放,无标准答案,引出"先试一周再选方案")
2. 如果标准版 具体档位与价格以 WorkBuddy 官方公告为准能帮你每天省 1 小时,一年省 250 小时值 1.5 万元——这个 ROI 12.6 倍的说法,你能用来跟上级汇报吗?(举手投票:能 / 不能 / 需调整)
