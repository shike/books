## 长版(~500 字)

**施可**(Shi Ke),水滴跃动(Dropleap)创始人,前邻汇吧 COO,中科大软工硕士。

**职业经历的三条线**:技术线(2009—2014,新加坡电信 NCS 与方正国际)→ 产品线(2016—2022,同程艺龙、哈啰酒店)→ 商业线(2022—2026,任邻汇吧 COO,半年业绩 +80%)。2026 年起 All-in AI Agent,创立 Dropleap。

**为什么写这套书**:在 50+ 企业 AI 落地项目里,我反复看到同一类问题——管理者买了 AI 工具,不会用、用不起来、用得不深入。**多数管理者买的是"AI 工具",缺的是"派活"能力。**

WorkBuddy 三部曲就是补这一能力:
- **第一卷 · 个人**:装上 WorkBuddy → 主界面与三栏 → 5 个高频场景 → 多模型路由 → 提示词 → 成本与积分 → 个人到团队(8 章)
- **第二卷 · 团队**:团队落地的三阶段 → 企业微信与远程协作 → 工作目录与文件规范 → 技能市场 → 专家中心 → 自动化 → 30 天培训手册 → 成本与权限(8 章)
- **第三卷 · 组织**:能力边界 → 自定义 Skill → API Key 与多模型策略 → 与企业系统对接 → 组织级 ROI → 变革管理 → 数据安全与合规 → 未来 12-24 个月(8 章)

**核心主张**:"管理者不必成为 AI 专家,但要学会派活。"WorkBuddy + 多模型路由 + 团队 Skill 库 + 组织级自动化,构成了"派活"的完整工具栈。
