# 更新日志 / CHANGELOG(三卷分别记录)

> 电子书与印刷书最大的不同:**可以持续更新**。
> 本日志采用 [Keep a Changelog](https://keepachangelog.com/zh-CN/) 格式 + [语义化版本](https://semver.org/lang/zh-CN/) 规范。
>
> **版本号约定**:`MAJOR.MINOR.PATCH`
> - **MAJOR**:章节结构 / 核心方法论变更,读者应重读
> - **MINOR**:新增章节 / 新增场景 / 重要补充
> - **PATCH**:错字、引用修正、格式调整
>
> **更新节奏**:三卷**独立版本号**,允许错峰更新(每月更新一卷)。
> **唯一可信源**:GitHub 仓库的 `promotion/CHANGELOG.md`。平台(KDP / 微信读书 / 豆瓣 / Apple Books)定期同步,最长滞后 24 小时。

## 反馈与勘误

发现错字、引用失效、场景描述不准等问题,请按 `feedback.md` 中的指引提交。
读者反馈会按严重程度分到下一版:
- PATCH(立即):错字 / 引用失效 / 明显事实错误
- MINOR(本月):场景细节 / 章节补充
- MAJOR(下个主版本):结构性问题 / 核心方法论质疑
