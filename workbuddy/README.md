## 📖 关于这个系列

本系列以腾讯云 CodeBuddy 团队于 2026 年 3 月发布的桌面端 AI 客户端 **WorkBuddy** 为对象,面向**资深职场人 / 团队管理者**读者,系统性介绍 WorkBuddy 的使用方法、团队落地路径与组织级应用。

## 🎯 目标读者

- 工作中需要高强度处理信息、做决策、带团队的中层及以上管理者
- 已有 ChatGPT/Claude 等对话式 AI 使用经验,希望把 AI 装进本机、嵌入工作流
- 不限于技术背景,但愿意为提升组织效率投入学习时间

每本书的 PDF 都包含完整的**出版级前置内容**:封面图、版权页(CIP)、AI 生成内容声明、关于作者、简介、致谢。

- **三卷分卷 PDF**:每卷都有完整前置(封面/版权/AI 声明/关于作者/简介/各卷序/各卷目录)
- **三卷合 PDF(workbuddy.pdf)**:
  - ✅ 封面 + 版权 + AI 声明 在 p.1-3
  - 🟡 关于作者 + 简介 在 p.36+ (因 Chrome 单次 headless 渲染 1.4MB HTML + 240 张图时内存吃紧,无法重出新版)
  - 💡 临时方案:三卷合 PDF 用的是早期版本(2026-08-17 14:16 生成),完整出版前置请直接看三卷分卷 PDF

### ⚠️ 已知限制:workbuddy 三卷合的 Chrome 内存问题

- 单次 Chrome headless 渲染 workbuddy 三卷合(1.4MB HTML + 240 张 PNG)时,主进程内存占用 1.5GB+,会卡住
- 已测试:三卷分卷各 50MB HTML 都没问题,但三卷合超出单次能力
- 如需重出 workbuddy 三卷合:
  - 方案 A:用三卷分卷 PDF + 各卷序拼装(放弃 1 文件合订)
  - 方案 B:用更激进的 Chrome 参数(`--single-process` 等)
  - 方案 C:拆分渲染(每卷单独出 HTML,Chrome 单独打印,然后用 PDF 工具合并)

## 🚀 快速使用

### 出版前 review(第一卷)
- PDF 阅读:`dist/第一卷.pdf` 或 `dist/workbuddy.pdf`(全套)
- 章节 md:`第一卷/chapters/01-管理者为什么需要桌面AI.md` ~ `08-从个人到团队.md`

### 企业培训交付
直接用 `培训物料/`:
- `题库.md` — 培训题库
- `讲师手册/` — 讲师用材料
- `学员手册/` — 学员配套
- `Vol1/2/3/module-cards/` — 培训卡片
- `Vol1/2/3/ppt-outlines/` — PPT 大纲
- `认证体系.md` — 认证方案

### 重新生成 PDF
```bash
# 三卷合(主书)
python3 ../scripts/build_book_pdf.py workbuddy --all

# 单卷
python3 ../scripts/build_book_pdf.py workbuddy --vol 第一卷
python3 ../scripts/build_book_pdf.py workbuddy --vol 第二卷
python3 ../scripts/build_book_pdf.py workbuddy --vol 第三卷
```

### 重新生成某章
按 `AGENTS.md` 规范,章号两位、标题 6-16 字、配图命名 `<卷号>.<章号>.<图号>-<描述>.png`。
